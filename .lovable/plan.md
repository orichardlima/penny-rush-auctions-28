# Juliano clicando no link do Janssen (já tendo conta de jogador)

## O que acontece hoje (nada precisa ser alterado para funcionar)

1. Ao abrir `https://showdelances.com/?ref=DGX0YX38`, o site guarda o código do Janssen no navegador do Juliano.
2. Se ele tentar **criar conta nova** com o mesmo e-mail ou CPF, o cadastro é recusado ("Este CPF já possui cadastro. Use outro CPF ou faça login"). Não é possível ter duas contas — isso é proteção antifraude.
3. Ao clicar em **Entrar** e fazer login com a conta que já tem, o código do Janssen continua guardado.
4. Quando ele for ativar o plano de parceiro, o código DGX0YX38 já aparece preenchido automaticamente. Ele não precisa digitar nada.
5. Com o pagamento confirmado, ele entra na rede do Janssen e o Janssen recebe os bônus.

Atenção: se ele abrir depois o link de outro parceiro antes de ativar, o código guardado é trocado pelo desse último link.
